# Biblioteca de Kor’hal — GitHub Pages

Site estático, sem cadastro. Abra `index.html` para testar (alguns navegadores bloqueiam `fetch` de arquivos locais; use `python3 -m http.server 8000` na pasta e acesse localhost:8000).

Para publicar: envie **o conteúdo desta pasta**, não o ZIP, à raiz de um repositório público GitHub; Settings > Pages > Deploy from a branch > main / (root).

O Livro I usa os 35 capítulos da versão anterior do site, extraídos dos documentos revisados; valide o conteúdo antes da divulgação.

Livro II tem introdução provisória, e ao avançar exibe Em breve. Registros ainda não publicados para evitar inventar cânone.

Contador: `VISITOR_COUNTER_URL` em `app.js` está vazio até conectar serviço externo; nunca mostra número fictício.
